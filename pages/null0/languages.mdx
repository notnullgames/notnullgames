<Callout emoji='🌍'>A cart is just wasm, so null0 can be written in anything that compiles to it. These 23 are the ones with real bindings, an example, and a docker image that builds them.</Callout>

Every language gets the _same_ API - the same functions, the same constants - spelled its own way. Pick whichever you already enjoy writing; you are not giving anything up.

You never install a toolchain. Each language has a `ghcr.io/notnullgames/null0-cart-<image>` docker image with the compiler (or interpreter) and the current null0 bindings baked in, so your project holds nothing but your game.
