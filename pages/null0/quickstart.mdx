<Callout emoji='🚀'>You need [docker](https://docs.docker.com/get-started/get-docker/) and [node](https://nodejs.org/). You do **not** need a compiler for whatever language you pick - that lives in the docker image.</Callout>

## 1. install system-tools

We use `npm` to record tasks, and docker to do the actual build. You can build carts without these, but it helps unify & simplify. Install these first:

- [docker](https://docs.docker.com/engine/install/)
- [node](https://nodejs.org/en/download)

## 2. choose a template

Pick a language from [our templates](https://github.com/search?q=topic%3Acart+org%3Anotnullgames&type=Repositories) and press **Use this template** to make your own repo. Every template is the same shape, whichever language you choose:

```
cart/         your game - source and assets. this whole folder becomes the cart
webroot/      the web player. only index.html is yours
package.json  the shortcuts below
```

## 3. make it your own

Search the project for `mygame` and change it to whatever your game is called. Stick to `A-z`, `0-9` and `_`.

## 4. run it

```sh
npm start
```

That builds `webroot/mygame.null0`, serves it on a local web-server, and rebuilds every time you save. Edit `cart/`, watch the browser.

To build once, without the server:

```sh
npm run build
```

Both are wrappers around one docker command, which you can always run yourself:

```sh
docker run --rm --user $(id -u):$(id -g) \
  -v ./cart:/src -v ./webroot:/out \
  ghcr.io/notnullgames/null0-cart-c mygame
```

<Callout emoji='📦' className='alert-soft'>
  Nothing about null0 is copied into your project. The docker image brings the bindings, and the web-player is loaded from null0's site.
</Callout>

## 4. publish it

The templates ship two github workflows:

- **Publish** deploys `webroot/` to github-pages on every push to `main`, so anyone can play your game at `https://<you>.github.io/<yourgame>/` without installing anything.
- **Release** attaches `mygame.null0` to any github release you create.

Players who want it natively download [the runtime](https://github.com/notnullgames/null0/releases) and run `null0 mygame.null0`.
