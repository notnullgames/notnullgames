<Callout emoji={<img src='/logo.svg' className='h-12 w-12 !m-0' />}>null0 is a small fantasy console. You write a game in whatever language you like, and it runs in a browser and natively on anything - mac, windows, linux, a raspberry pi.</Callout>

<Null0Cart src={`${CDN}/carts/demo_lua.null0`} />

A game is a ["cart"](/null0/cart): a zip file with `main.wasm` in it, plus your assets. Anything that compiles to WebAssembly can be a cart, and <strong>{languages.length} languages</strong> have real bindings, examples, and a docker image that builds them - from C, Rust and Zig to Lua, Python and Haskell.

[The API](/null0/api) is small enough to learn in an afternoon: draw things, play sounds, read input, load a Tiled map. Every language gets the same one.

- [Quick start](/null0/quickstart) - a running game in about two minutes
- [Languages](/null0/languages) - pick yours, and see what a cart looks like in it
- [Gallery](/null0/gallery) - all {cartList.length} example carts, playable
- [The project on github](https://github.com/notnullgames/null0)

It is good for learning, for jams, and for the kind of small game that should not need a 3GB engine.
